# 自定义视觉资源目录

本目录用于放置用户可自行替换的图片资源，App 启动时通过 `loadCustomAssetDrawable` 顺序尝试以下后缀加载：

- `.png`
- `.jpg`
- `.jpeg`
- `.webp`

## 资源清单

| 文件名 | 用途 | 推荐尺寸 |
|--------|------|----------|
| `background` | 首页/统计/规则页通用背景图 | 1080x1920 |
| `medal_gold` | 金牌图标 | 256x256 |
| `medal_silver` | 银牌图标 | 256x256 |
| `medal_bronze` | 铜牌图标 | 256x256 |
| `reward_qr` | 开发者赞赏码 | 800x800 |

## 使用方式

将真实图片放在本目录下，文件名（不含后缀）必须与上表完全一致。App 会自动按 png/jpg/jpeg/webp 顺序尝试加载，找到第一个即返回。不需要改任何代码。
