# 鼠标滑动控制器

作者：寒枫  
反馈群：573309536

这是一个桌面鼠标控制工具。用户设置开关热键、滑动方向和滑动频率后，可以通过界面按钮或热键开启功能；按住鼠标左键时鼠标会按配置缓慢滑动，松开左键停止滑动，再按一次热键关闭功能。

## 功能

- 界面提供开启/关闭按钮。
- 自定义开关热键，例如 `a`、`f8`、`space`。
- 支持点击“录制热键”后直接按键盘任意按键设置热键。
- 自定义滑动间隔，支持快捷选择 `0.5 秒`、`0.1 秒`、`30 ms`，也支持小数，例如 `12.5ms`。
- 支持用户主动开启分阶频率，用“时间”和“频率”两个输入框设置，例如时间 `1.5`、频率 `50ms`。
- 自定义滑动方向，可选择上下左右和四个斜角，也可直接填写 0-360 度角。
- 界面提供太阳/月亮按钮，可以在白底黑字和黑底白字之间切换。
- 自动记住上次配置，重新打开后会恢复热键、方向、频率和主题。
- 支持创建多个配置，每个配置可以设置独立名称、切换热键、方向和频率。
- 高级用户也可以直接填写精确 X/Y 数值。
- 左键按住时工作，左键释放后立即停止。

## 运行

```bash
# 安装依赖
pip install --break-system-packages -r requirements.txt

# 启动程序
python3 mouse_controller.py
```

Windows 用户可以参考 [PACKAGING.md](PACKAGING.md) 使用 `PyInstaller` 打包成 `.exe`，也可以放入 `app.ico` 自定义打包图标。

## 配置说明

- `开启/关闭`：点击按钮可直接切换功能状态。
- `滑动间隔`：数值越小移动越频繁，默认 `30 ms`；可以选择 `0.5 秒`、`0.1 秒`、`30 ms`，也可以手动输入 `12.5`、`12.5ms`、`0.1s`。
- `启用分阶频率`：默认关闭，关闭时使用固定滑动间隔；开启后会显示分阶频率输入框。
- `分阶频率`：填写时间 `1.5`、频率 `50` 时，按住鼠标左键 `1.5` 秒后，滑动间隔会变成 `50ms`。
- `滑动方向`：可选“向上”“右下”“左上”等方向，快捷按钮会显示对应角度。
- `角度`：`0` 向右，`90` 向下，`180` 向左，`270` 向上，支持任意 0-360 度。
- `精确 X/Y`：由角度自动换算，便于查看当前方向。
- 右上角图标按钮：太阳图标表示当前白色主题，点击切换到黑色主题；月亮图标表示当前黑色主题，点击切回白色主题。
- `开关热键`：设置后按该键可切换开启和关闭。
- `录制热键`：点击后按键盘任意键，例如字母、数字、方向键、空格、回车、F1-F12。
- `配置`：点击后打开配置管理窗口，可新建、保存、应用和删除多套配置。
- `配置切换热键`：每套配置都有自己的切换热键，例如配置1 用 `f6` 切到左下 30ms，配置2 用 `f7` 切到右下 20ms。
- 热键会自动统一格式，`F6`、`f6`、`Key.f6` 会按 `f6` 处理，`空格` 会按 `space` 处理，主键盘数字和小键盘数字都会按 `1`、`2`、`3` 这样的数字处理。
- 默认配置为热键 `a`、每 `30ms` 向下滑动。
- 配置会自动保存到用户目录，例如 Windows 的 `%APPDATA%\MouseSlideController\settings.json`。

## 使用步骤

1. 打开软件后，先设置 `滑动间隔`，建议从默认 `30 ms` 开始。
2. 需要逐步改变速度时，勾选 `启用分阶频率`，再填写 `时间` 和 `频率`，例如时间 `1.5`、频率 `50`。
3. 选择滑动方向，或者直接输入 0-360 度角。
4. 点击 `录制热键`，按下你想用来开关功能的键，例如 `A`、`F8`、`空格`。
5. 点击 `配置`，给当前参数保存成配置，并填写切换热键。
6. 需要多套动作时，继续新建配置，例如左下 30ms、右下 20ms。
7. 点击 `开启`，或者按刚设置的开关热键开启功能。
8. 按住鼠标左键，鼠标会按当前配置滑动。
9. 按配置切换热键即可切到另一套配置。
10. 松开鼠标左键，滑动立即停止。
11. 再按一次开关热键，或者点击 `关闭`，功能关闭。

## 主题切换

- 太阳图标表示当前是白色主题，点击后切换到黑色主题。
- 月亮图标表示当前是黑色主题，点击后切换回白色主题。

## 注意事项

- Windows 和 macOS 可能需要给终端或 Python 授予辅助功能、输入监听或无障碍权限。
- 软件使用全局键盘监听，窗口最小化或切到后台时热键仍然生效。
- Linux 桌面环境需要支持全局输入监听；Wayland 环境可能限制全局监听能力，X11 兼容性更好。
- 关闭窗口会停止键盘和鼠标监听器。
